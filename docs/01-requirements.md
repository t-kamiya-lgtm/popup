# 01. 要件整理

## 1. 目的

EC サイトの離脱直前・滞在中の任意タイミングでポップアップバナーを表示し、
離脱防止 / クーポン配布 / SNS 送客 を行う。効果は imp・click・CV で計測する。

導入側の要件は「リンク先ページにタグを埋め込むだけで設置できる」こと。
= サイト側の HTML 改修は **共通タグ 1 行 + サンクスページの CV タグ 1 ブロック** のみ。

## 2. 用語

| 用語 | 定義 |
| --- | --- |
| サイト (Site) | 計測単位となる EC サイト。1 サイト = 1 タグ ID |
| キャンペーン (Campaign) | 「どのページで・どんな条件で・どこに出すか」を定義する配信設定の単位 |
| クリエイティブ (Creative) | キャンペーンに紐づくバナー 1 パターン（画像 + リンク先 URL） |
| ページグループ (Page Group) | レポート集計単位。商品ページ等を URL ルールでまとめたもの |
| imp | ポップアップが実際に画面に表示された回数 |
| click | バナー本体（リンク領域）のクリック / タップ回数 |
| CV | 成果地点（購入完了等）到達回数。ポップアップ接触にひもづくもののみ |

> 補足: 依頼文中の「基幹指定」は「**期間指定**」と解釈しています。
> （基幹システム連携の意図であれば別途調整）

## 3. 機能要件

### 3.1 配信（フロント）

- **トリガー**（複数を OR 指定可、AND 条件も可）
  - `exit_back` : ブラウザバック操作の検知（PC / SP 共通）
  - `exit_intent` : マウスがビューポート上端から離脱（PC のみ）
  - `dwell` : サイト訪問から N 秒経過（例: 60 秒）
  - `scroll` : ページの N% までスクロール
  - `idle` : N 秒間無操作
  - `exit_tab` : タブ非アクティブ化 (`visibilitychange`)
- **配信対象ページ**: URL ルール（完全一致 / 前方一致 / 含む / 正規表現）の許可リスト + 除外リスト
- **配信対象条件**: デバイス（PC / SP / TAB）、新規 / リピーター、参照元、日時（曜日・時間帯）、配信期間
- **フリークエンシー制御**: セッション内 N 回まで / 1 日 N 回まで / 閉じたら X 日間非表示 / クリック後は非表示
- **表示位置**
  - SP: 画面中央（固定）※将来拡張で下部固定バーを想定
  - PC: `bottom_right` / `bottom_center` / `bottom_left` / `center` から選択
- **複数クリエイティブの均等配信**: 有効クリエイティブ数 n に対し 1/n で配信（ラウンドロビン）
- **クリック時遷移**: クリエイティブごとにリンク先 URL・ターゲット（同一タブ / 別タブ）指定
- **閉じる操作**: × ボタン / オーバーレイクリック / ESC キー

### 3.2 管理画面

- クリエイティブ登録（画像アップロード、リンク先 URL、代替テキスト）
- 画像は**自動最適化**（リサイズ / WebP・AVIF 変換 / 2x 生成）
- **SP / PC の表示プレビュー**（実配信と同じレンダラを使用）
- キャンペーン設定（対象ページ・表示条件・表示位置・期間・フリークエンシー）
- 実績レポート
  - 期間指定
  - ページグループ（商品ページ）別
  - クリエイティブ別
  - 指標: imp / click / CTR / CV / CVR / CV 単価相当（売上金額）
- ユーザー / 権限管理（管理者・編集者・閲覧のみ）

### 3.3 計測

- imp: ポップアップ DOM が可視状態になった時点で 1 回（同一表示につき重複送信しない）
- click: バナークリック時（`sendBeacon` で確実送信してから遷移）
- CV: サンクスページの CV タグ発火時、直近のポップアップ接触にひもづけ
  - クリックスルー CV（既定 7 日）
  - ビュースルー CV（既定 1 日）※レポート上は分離表示

## 4. 非機能要件（サマリ）

| 項目 | 目標 |
| --- | --- |
| タグ初期ロード | ローダ gzip 4KB 以下 / 完全非同期 / CLS 0 |
| 配信設定取得 | CDN エッジ配信、p95 100ms 以下 |
| 表示までの遅延 | トリガー発火から 100ms 以内に描画 |
| 計測欠損 | `sendBeacon` + リトライで 1% 以下 |
| 可用性 | 配信系 99.95% / 管理画面 99.5% |
| 影響範囲 | 設置サイトの JS 例外に巻き込まれない（全処理 try/catch・Shadow DOM で CSS 隔離） |

## 5. スコープ外（初期リリース）

- A/B テストの統計的有意差判定 UI（データは取得しておく）
- 入力フォーム付きポップアップ（メアド取得等）
- 外部 MA / CRM 連携
- クーポンコードの発行・在庫管理（コードは静的文言として画像 / リンクに含める）
